# 공개 인계판

이 저장소의 Git 기반 협업 인계 정본은 이 `board/` 디렉터리다.

- 현재 상태: [STATE.json](STATE.json)
- 판단 기록: [decisions/](decisions/)
- 판단 기록은 한 건당 한 파일로 추가하며 기존 기록을 덮어쓰지 않는다.
- 비공개 SAVE 본문·회차 서술·개인 참조 이미지·비공개 데이터 내용은 이곳에 복사하지 않는다.
- 공개 가능한 범위는 커밋 해시, 자산 수, 세계선 이름, 남은 작업, 운영 판단과 스크립트다.
- 역할은 채팅 고유명보다 `진행 채팅 / 규칙 검증 담당 / 이미지 생성 담당 / 리소스 관리 담당`으로 기록한다.
- 작업 시작 시 `STATE.json`과 최신 decision을 읽고, 완료 시 확인된 단계만 갱신한다.
